## Statement and exact premises

Fix any integer K. Measure input clocks t from one lower boundary.
Assume no physical errors, the actual own ROM, initial807 reset bits0,
and arbitrary initial raw Info copies. D(y) is the initial majority of
the five Info holders of physical logical primary y. These labels use
the fixed copy slots, not the native GF field.

Up to the special-write input clock TS=278400, require the following
**actual native interface at every physical site and every input row**:

* Computed old Age is age_code(t), and stored native Age is common.
* Computed GF and refined raw self-GF agree with the quiet T(K,K+6)
  profile: GF is shifted512 on[(K-1/2)Q,(K+6)Q), canonical elsewhere.
* Computed F1 is1 exactly on[(K-1)Q,(K-1/2)Q) and
  [(K+11/2)Q,(K+6)Q), and is0 elsewhere.

Thus keep=1 globally throughout this prefix. These are premises about
the actual history, not a prescribed encoding or a consequence of a
local cofactor alone. The known quiet-template GF/native identities
have symbolic common clock; empty service/header forces are needed
to establish them in an actual history. Their all-period supply is
outside this theorem.

Complete true frames have origins o=jQ for j<=K-2 or j>=K+6.
Complete foreign frames have origins o=hQ-512 for K<=h<K+6.
In each, all required physical holders have computed relative GF
(x-o)modQ. Define that frame's abstract input assignment v by:

    v(0,field,bit) = D(o+a),
    v(d,field,bit) = D(o+a+dQ) if its physical mail route is unblocked,
                     0 otherwise,

where a is the corresponding normal layout phase and d is one of
that bit's dependency offsets. A route is blocked if an eight-site
lattice step, including load/receiver points, meets a quiet F1 strip.
No relation between different input bits is assumed. Thus v is one
raw neighbourhood assignment, without a common upper clock, upper
copy coherence or an upper self-encoding hypothesis.

**Prefix conclusion.** All three actual captures used by this frame
equal the indicated v. Every actual ordinary instruction up to TS
executes the frozen symbolic programme on v. Its GF and early native
F1/F2 Hold stores materialize at the certified clocks before TF278401.
All five copies agree. Actual couriers deliver the early F1 to o+1021
and F2 to o+3 at computed row TF; their five Info holders are coherent.

There is also a conditional late conclusion for a complete true frame.
In addition to the prefix premises, require through evaluation/commit:
the common legal clock continues; on the entire frame's remaining
holder/source footprint the actual computed relative GF is unchanged
and equals refined self-GF, hence keep1. Captures have ended and no
new gather is enabled. The normal Info snapshot then remains unchanged
by the literal carry/special guards. The full programme executes on v with **some coherent
26-bit Match word I0**. Every normal Hold equals the full Boolean
function F30(v,I0) at the registered materialization clock. Native
GF/Age/F1/WF1 outputs are independent of I0. The actual commit
forwards these Holds and resets work under its literal commit premises.
No correct simulated Pi lookup or upper intactness is required for
these particular native outputs. Full decoded upper-data correctness
would require its own correct Match hypothesis.

For use after J207, full true frames j<=K-9 have the geometric reserve:
their required SF footprint lies in[jQ+1,jQ+1023], with native reads
at most37 farther. This lies strictly left of the all-row GF hull
[KQ-7616,(K+6)Q]. Common legal Age and that canonical GF reserve
give the native/keep part of the late premises; the largest native
read is at (K-9)Q+1060=KQ-8156,540 sites before that hull.
The actual common-clock and GF-hull history must still be discharged
in the assembly. The1021 courier endpoint has a holder at1023;

This correction preserves the reserve inequality and changes no rule.

## Physical mail and captures

The separate exact mail probe leaves all old raw fields and I free,
substituting only the stated conditional native interface. At legal
gather clocks, it identifies all15 Info/Mail copy-output nodes with
the literal fixed-primary vote and load/fast/slow formulas. Its15
free low clock bits cover every legal clock0..E0=25984; high bits0
close commit, couriers and special-write guards. This is a symbolic
function identity, not a payload sample.

For Info, away from the two special writes and commit, new copies
are the old five-holder vote. Thus after the first transition all
copies of every D(y) agree, even if the initial raw holders did not.
This logical snapshot persists until TS. Normal layout phases avoid
3/509/515/1021 under both possible GF phases, so their physical Info
snapshot also survives the special-write row.

Each new Mail copy has one common old voted value multiplied by its
holder's native unflagged gate. Majority of five such copies is that
common bit times majority of the gates. For each quiet512-site strip,
the latter is exactly the centre primary's gate G(y). The28 boundary
cases are checked; uniform intervals and integer translations follow
from the same five offsets. Hence actual voted Mail satisfies

    M_(t+1)(y) = G(y)D(y)            on a gather load,
    M_(t+1)(y) = G(y)M_t(y+/-8)      during fast transport.

This is a physical majority recurrence despite holder-dependent raw
Mail values. Iterating multiplies D(source) by the route's gates.
A512-site strip cannot be skipped by steps of8. At input clock
gQ+abs(d)Q/8+1, capture reads the old row after exactly abs(d)Q/8
fast updates since load produced row gQ+1. It therefore reads
D(o+a+dQ) if unblocked, and0 otherwise. The111 timing checks
cover gathers0/10/20 and distances1..37. The last capture input25217
produces row25218, before evaluation25984.

For each complete-frame normal primary, all five holders are inside
its linear-GF interior. Their computed Address+slot is the same a,
so the actual sparse-control table enables the same rank/direction
at all holders. The capture update is consequently coherent. The
three captures agree because the snapshot and gates are constant.
The third majority leaves that same bit in h1, and h2 contains the
second value. No later capture can overwrite them. This supplies
the actual programme operands, rather than a prepared history bank.

## Registers, ROM, pending stores and turns

At page n and within-page tick s, the five virtual comb centres are

    c_f = 38 + (s if n even else 927-s) + 5f, f=0,...,4.

The centres range38..985; old compact-register majority sources are
within35..988. The five register windows, each five consecutive
sites, are disjoint. Every update has at most one arriving logical
primary at a holder. At a turn the old and new centres coincide;
otherwise source centres are the previous positions one site away.
The checker verifies1,781,760 holder visits and1915 turn interfaces.
None wraps or touches a complete frame's geometry discontinuity.

Start uses zero registers. Inductively each compact register window
has five equal copies of its frame/front's register word. Its selected
old register majority is therefore exact. Info/h1/h2/scratch/Hold
operands are the corresponding fixed-primary corrected words; every
actual Info/history read is at a normal phase with a declared rank.
The holder's computed Address and common clock identify the same
logical target and ROM column at all five holders. Thus all execute
the same frozen instruction and produce the same new register word
and pending payload. An adjacent partial frame cannot enter these
interior windows: arrivals are fixed by local relative GF/clock and
the nearest needed old register position is35 sites from the origin.

Pending writes have one destination kind and payload across their
five copies. Logical reads forward the voted pending write; the next
raw update materializes it. The registered symbolic schedule's
scratch delay>=1 matches that forwarding order. Zero ROM words
only compute register0 AND itself, preserving register0 and every
other carried register; skipping them in the abstract interpreter is
exact. The literal non-arrival and Match gates issue no stores.
The physical register/pending/scratch induction therefore couples
each ordinary visit, including pass turns, to the registered abstract
programme on v. It covers all payload bits, rather than sampled traces.

The13 early Hold destinations (GF59..68, F1phase88, flags58/965)

All five holder groups and the paths from58 to3 and965 to1021 lie

## Match without assuming a correct upper instruction

Match is page289, after the early stores and the pulse interval.
Only register bits10..35 (26 bits) can change on a matched answer;
other bits are carried. During a complete protected frame's Match
pass, the five holders have the same corrected register word, virtual
target and selector, hence the same ROM answer and match predicate.
They remain coherent even if a key never meets an answering phase.
The raw key may be any10-bit pattern. The ROM is total on all1024
addresses and4096 selector values, so no answer is undefined.

The key's address bits0..9 are carried during Match. Each comb front
visits each eligible answering phase at most once. Its final bits10..35
are consequently some coherent26-bit word, either the answer or the
carried value when there was none. Selector bits overlap the replaced
word; no constant-selector premise after an answer is needed. In
particular we do not assert that this word equals the intended upper
instruction in a damaged/incoherent upper neighbourhood.

The registered abstract checker discards **every** register value
at the Match boundary, retains only front0 bits10..35 as independent
I inputs, and rejects every subsequent register read lacking a prior
definition. Repeating that definedness check on all131238 actual
instructions succeeds. Thus all other physical Match outcomes and
carried register values are irrelevant to every subsequently used
value. Supply the actual front0 word as I0. The ordinary-visit physical
induction then gives exactly the universal symbolic evaluator result.

Finally the full compiled graph's10 GF,19 Age,1 F1 and1 WF1 outputs
have no structural I-input dependency: the checker propagates26
dependency bits through every gate and finds0 at all31 outputs.
Therefore native conclusions from J210/J208 hold for the actual
I0, whatever its value. The22 registered equalities are lookup-key
bits (10 address+12 selector), not the width of the loaded word.
