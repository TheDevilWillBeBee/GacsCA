# GE0: actual three-history native evaluation and early flag couriers

GE0 is a new, isolated **conditional physical-prefix component** at
Q=8192, U=128Q=1048576, lambda=24 and c=104. It connects the frozen GT0
three-history input to a real finite moving head and then to the two
special SimBit primaries. Its emitted 2346-bit programme evaluates the
literal printed native rule. It is **not** an own programme for the full
component, a complete Gray automaton, a faster-U rule or an error theorem.

## Precisely conditional statement

Take the GT0 prefix interfaces and the single shared clock-only row0 fault
on[0,17Q) of the accepted first-bank theorem. Use GE0's declared2462-bit
frame, with native primary residues2865..2901. Suppose a final completion
supplies an intact recursive encoding of this layout and a Q-bit programme
which contains the emitted native-prefix code at residues2929..5274.
This final completion and own programme remain premises. Other code bits,
the first History bank and all initial extra GE0 fields may be arbitrary.
No independently selected upper errors or preloaded native banks are used.
There are no errors after the stated row0 fault. Retain the printed native
rule, GT0 equations and Workspace window; use GE0's new early schedule and
head/Out/courier equations. Final fifth-stage stores remain integration
ports. They cannot affect the prefix in this statement.

For lower receivers15 and16, at each represented native-bit primary the
actual History2 and History3 inputs supplied by GT0 are those of the
first-bank theorem. GE0's real head reads their bitwise temporal majority
with the actual arbitrary first History. It halts at local computed
Age599648, with output GF equal to the receiver, Age1, Flag1=1, Flag2=0.
The actual flag couriers reach logical primaries Q-3 and3 by Age619691.
At GT0's existing delivery Age655359=80Q-1, all five SimBit copies at
Q-3 become1, and all five copies at3 become0. This is a physical delivery
lemma for the conditional prefix, not a later Workspace/clock-recovery
claim. The analogous prepared native-input theorem holds for arbitrary
legal native words; it does not assert their reachability from this fault.

## Declared component and departure ledger

The frame contains37 native bits,240 actual GT0 bits,2170 bits for five
copies of a434-bit head, and5 copies each of EarlyOut/CourierL/CourierR.
Its2462 represented raw bits fit in a centred frame[2865,5327); twice its
width is4924<=Q. This is a **declared component layout**, not certification
that a final own-rule evaluator or all Gray service fields fit that frame.
The native columns are GF2865..2877, Age2878..2897, Flag1/Flag2 at2898/2899,
and Workspace1/2 at2900/2901. All native primaries are in[5,Q-5], so the
accepted GT0 bank proof applies without importing its preliminary layout.

The moving head retains GMW0's finite word instructions, sixteen20-bit
registers, thirteen-bit PC and434-bit packet. Its local migration reads
actual five-holder votes at logical y-1,y,y+1. Its code fetch reads the
fixed Q-bit beta at the **old raw Address of the logical source cell y**,
not the holder's Address or an immutable large instruction dictionary.
Every invalid packet, collision and instruction retains the frozen total
ERROR semantics. LOAD reads eleven bits at the current tape column, each
bit formed from three actual voted GT0 History fields. No instruction
calls the native rule or a whole-rule host evaluator. The emitted code
implements native arithmetic using the generic instructions.

This is an explicitly added early bank/reset/birth/run pass and two
speed-one couriers. GT0's five stage endpoints and total U are unchanged;
an extra evaluator before the usual fifth stage is nevertheless a
schedule/interface change. Native evaluation preserves Gray's printed
Flag2 predicate, including its previously certified printed-clause flaw;
no h1 correction is silently made. GE0 does not supply late Workspace
equations, final computed-SimBit/wipe ordering, late writeback, mutable
ProgrammeBits, hardwirer composition or a whole own beta. Its all-raw map
is a **component with two late Workspace and five fifth-store ports**.
The half-open Workspace window[96Q,98Q) and fifth store clock gate are enforced.
Before80Q these ports cannot supply an oracle or change the claimed prefix.

## Actual raw-holder equations and locality

For a logical coordinate y and a component field f, write

    V_f(y)=majority_5(raw holder[y-s].f_copy[s], s in{0,-2,-1,1,2}).

GE0 uses exactly this value even for incoherent raw copies. Its temporal
tape bit is majority_3(V_History1(y,b),V_History2(y,b),V_History3(y,b)).
The first-bank theorem supplies equality of the latter two for the actual
history. Thus the tape is their bank independent of the first value.
History2/3 are held through the early run: their last reset/capture is
earlier, and their next reset does not occur in that interval. Native
GF is canonical; SF wipe is therefore false, including in the flagged
lower colony16. Mailbox erasure does not erase History, Head or EarlyOut.

At calculated Age69Q+3, Head/EarlyOut/CourierL/CourierR are reset to0. At
69Q+4, a head is born exactly at raw logical Address2929. Subsequent
calculated Ages strictly between that birth and75Q migrate the old voted
head and apply one generic step. Outside this run they retain voted values.
Writes modify only EarlyOut at the physical tape column; untouched outputs
were reset to0. GF/Age controls at all execution holders are canonical
and common within their own colony. The whole execution corridor is
contained in residues2865..5274, with its radius-five footprint strictly
inside the colony. All five output copies therefore use the same phase
and same raw-source Address, despite the offset clock in other colonies.
Reset gives uniqueness, birth gives one head per colony, and the frozen
migration induction preserves uniqueness and five-copy agreement.
Private fields at neighbouring colonies cannot inject another head into
this corridor after reset: before reaching a boundary the unique head
always remains in that corridor. This proves the physical lift, rather
than assuming a unique head on a prepared tape indefinitely.

All raw dependencies are bounded: GT0, tape and local field votes use
offsets at most4; incoming-head votes use s+j-t, with |s|,|t|<=2 and
|j|<=1, hence at most5. Beta reads old raw cells[s].Address, |s|<=2.
Native controls use radius5. Courier target lookup at delivery selects
a logical offset in[-2,2], so its raw-holder footprint is at most4.
No source's *computed* native field is read. Native/SF wipe follows the
literal component comparison. All operations mask to their stated finite
widths; Workspace/fifth-store ports are finite bits. Thus every raw
component/port input has a total radius-five evaluation. This does not
make the programme an own evaluator of that entire evaluation.

The raw-Address birth defect under general E0 GF overwrites remains:
one overwrite at the entry can suppress every birth holder. GE0 does
not repair it and claims no arbitrary-E0 extension. The clock-only
history here preserves raw GF and therefore satisfies the birth premise.

## Exact programme and deadlines

Relocation leaves the frozen107 native instructions and all memory travel
distances unchanged. They occupy2346 consecutive beta bits starting2929,
ending just before5275. Every branch is forward, crosses no memory
operation and rejoins before the next memory command. A taken branch
walks the skipped code locations rather than evaluating them, so total
time is independent of the native values. For an IO instruction ending
at e, tape start a, width w and return PC r=e+1, its extra cost is

    |e-a|+(w-1)+|a+w-1-r|-1.

The literal listing gives32050 extra ticks and2346 code ticks, total34396.
The frozen register contracts prove the resulting35 GF/Age/Flag outputs
equal the literal native equations on every legal eleven-word input.
GE0 changes only the bit-column addresses and source of LOAD; the
instruction/register contracts and input-independent timing apply verbatim.
The code beta outside[2929,5275) is never fetched on the valid run.

The latest third gather is ready at Age69Q+2=565250. Reset is69Q+3=565251,
birth69Q+4=565252, and the first execution update is565253. Halt occurs
at birth+34396=599648, before courier seed75Q=614400. There are49147
available execution updates strictly between birth and seed, leaving
14751 after halt. The birth tick is explicitly excluded.

At Age75Q, CourierL is seeded from the old EarlyOut bit at primary2899;
CourierR from primary2898. All other courier columns become0. CourierL
then shifts left one logical site per calculated update for exactly
2896 ticks, reaching3 at617296. CourierR shifts right5291 ticks, reaching
Q-3 at619691. Each field then holds; its corresponding motion stops
before passing the colony boundary. All holders at the target residues
are inside their own colony and share its phase. Consequently each old
target vote at Age80Q-1 equals its own produced flag, and the existing
GT0 port equation writes all five special SimBits. The right route has
35668 ticks of slack to delivery. No modified stage endpoint or faster U
is needed for this component.

For the actual first-bank inputs, both results have Flag1=1/Flag2=0.
The positive Flag1 source is real; the Flag2 result is not a positive
repair command. A separately labelled prepared bank with correct common
Age15 and five null right words computes Flag2=1 and uses the same
courier, but this prepared test does not establish sixteen reachable
common-Age banks or a later repair history for the actual island.

## Verification and status

instruction, verifies each IO excursion and branch, and replays the
actual new local transition on retained native-bank/head/courier/source
contexts. Physical tests are receipts, not a substitute for the copy,
register and routing inductions above. Unconditional whole-rule claims
are deliberately absent.
