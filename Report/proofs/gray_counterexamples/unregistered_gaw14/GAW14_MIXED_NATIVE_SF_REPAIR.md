# GAW14: selected actual mixed-native/interpreter bursts repair by 2U

This is a **positive finite repair checkpoint**, not a counterexample.
Ten chronological original-c104 real1 errors in the frozen total GAW2R
produce only legal normal upper records in one adjacent pair at U, and
their full infinite-line states coincide with the clean shadow at 2U.
Some forged packets execute while native GF/Age are wrong; some survive
native healing and write later. These cases therefore go beyond a
zero-Head native factor. Their effects are still permitted sacrificed
upper records. There is no universal mixed-noise, Gray, Gács, iid memory,
positive noise-rate or smaller-U theorem here.

All old GAW0–13 and registered main files are unchanged. The new C/Python
factor is an evaluation shortcut for exactly the old transition, not a
new automaton. Every recorded first/future phase, bank, command, Head,
Out and reset comes from the same original fault; none is independently
chosen after that fault.

## Exact active factor and its restrictions

[C factor](gaw14_active_factor.c) includes the frozen GAW9 native
transcription read-only. Its new work is readonly-copy voting and
Programme filling. [Python factor](check_gaw14_active_factor.py)
executes every affected mutable holder with the actual step_packet,
and separately [the full-prefix executor](search_gaw14_mixed_active.py)
calls the frozen whole local_R when resets or births can open.

The factor is conditional on every computed native clock being in a
strict active interval with no reset, birth, gather/capture, courier,
commit or WF source equation enabled. The exact accepted intervals are
72Q+4<Age<75Q or 102Q+1<Age<=120Q; the selected future uses the latter.
The C routine checks this for every computed cell at every step and
rejects on failure. Consequently computed WF1=WF2=0 is a consequence
of the actual guard, not a prescribed future input. Old native WF can
be nonzero only when supplied by the original fault; its next output
is computed normally. Mail/couriers start zero and remain zero; native
F1 clearing Mail cannot create a value. Captures are closed. These
facts derive all fields omitted from the mutable executor.

For logical y and holder h at physical x=y-S[h], put K(x,h) in {0,1}.
The readonly representation is

    Mem_h(x)=H1_h(x)=H2_h(x)=H3_h(x)=B(y) K(x,h),
    Info_h(x)=I(y) K(x,h).

Since voting is bitwise 3/5, for any fixed coefficient word W_y the
vote of five W_y K copies is W_y times the majority of the five K
bits. The exact new tag is that majority unless the *actual holder*
wipes, i.e. computed F1(x)=1 and computed GF(x)!=raw GF(x); then it
is zero. This is the raw-GF wipe of GAW2R, not a refined-self-GF
replacement. Programme is separately refilled with
beta[(computed GF(x)+S[h]) mod Q], or zero on a wipe; all old Programme
words in these histories are boolean, as required by the C bit track.

For each logical target y the Python executor votes old Head/Out/
Scratch, computes incoming movement from y-1,y,y+1, and calls the
actual packet step **five times**, at the five holders' service
Addresses (computed GF(x)+S[h]) mod Q. It uses the old voted Mem and
Programme. If that holder wipes, all its new working outputs are
zero. The five computed Addresses need not agree before GF recovers;
using the head-centre GF instead would be an incorrect shortcut.
Coherent old Out/Scratch groups with no incoming Head and no current
wipe remain unchanged. All other groups, including incoherent ones,
are recomputed. This proves the derived active equations by direct
substitution into every clause of local_R. It does not assume correct
GF, native flags, Head uniqueness or a quiet SF bank within the active
component.

The C array covers [-2Q,4Q+64). Every row rejects if a native/readonly
disturbance approaches its twenty-site margin; the Python executor
also rejects a mutable target at its finite margin. Exterior native
and readonly state is the exact canonical shadow. No disturbance
ever reaches either cut in the accepted traces. Missing clean mutable
heads outside receivers -2..2 execute their own clean frames, disjoint
from every actual noisy/moving-head group. There is no wall-caused
repair: induction on the actual dependency neighbourhood extends
the finite representation to the infinite line. C computes every
native update; old readonly tag zeros, Programme bits and changing
mutable groups are retained with complete event hashes and packets.

The 256 mixed-native cofactors compare the new factor with the full
local_R under arbitrary GF/flags in its legal clock window, arbitrary
mutable Head/Out/Scratch words, arbitrary readonly coefficients/tags
and boolean Programme bits. They include 320 real store-holder cases,
320 wipe-holder cases and 960 nonwipe-holder cases; 16640 SF holder
assignments are checked. Sampling supplements the algebraic clause
derivation. It is not a universal random-input proof, nor does it
cover arbitrary 20-bit clocks or arbitrary mutable Programme words.
Selected histories additionally retain full whole-kernel cofactors
at their actual boundaries, fronts, packet positions and early rows.

Only then does the active-phase contract apply. A coefficient B(y)=0
and I(y)=0 makes either tag observationally equivalent; the importer
