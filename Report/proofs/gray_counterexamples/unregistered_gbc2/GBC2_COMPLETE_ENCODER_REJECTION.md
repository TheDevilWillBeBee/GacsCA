This checkpoint keepsQ=8192, U=128Q=1048576, lambda=24 and the original
integer error-class constantc=104. It does **not** produce aQ-sized own

## 1. The total declared rule and the unfinished construction

`compact_completion_rule.py` declares a total radius-eight binary rule
F_beta for every immutable beta in{0,1}^8192. Its native state is
GF13/Age20/F1/F2/WF1/WF2; its simulation fields have five interleaved
copies. There are17 input lanes, a553-bit Head, a407-bit mutable Work,
two Word20 arithmetic registers, and13-bit PC/return. The represented
frame hasK=3087 and2K=6174<Q. All native words are full legal-width
bit patterns; SF words and the five holder copies need not be coherent.

The total upper-input quantifier contains every bit pattern of those
fields, including arbitrary/incoherent Head, History and otherSF. It is
distinct from the prepared *lower execution* assumptions used in the
diagnostics: stable exact input banks, initialized executing head,
correct lower geometry/control, no execution wipe and no physical error.

This rule changes Gray's representation, radius, programme storage and
control. It uses the correctedh1 Flag2 erasure, binary17-lane gathering,
immutable code instead of mutable ProgrammeBits/hardwirer, the new
generic ISA, holder-computed native service addresses, and explicitly
specified collect/courier/final-source equations. Its three gathers and
Flag1 Mail erasure preserve those *forms*, not a proved refinement of
Gray's whole protocol. KeepingQ/U/lambda/c does not transport his
radius-five error estimates. No shorterU is proposed here.

The construction needs an own beta whose actual interpreted output is
F_beta on every total raw input, plus a universal execution deadline and
a physical period composition. K fitting is necessary but supplies none
of these missing obligations.

## 5. Actual compaction result and remaining work

`compact_complete_emitter.py` reuses the complete frozen emitter and
merges only the repeated continue_pc output tail. It changes no opcode,
state bit, rule equation or counted software Work location. Every
continuation either retainsVPC or copies its return source intoVPC,
then branches to the one common output tail. The original output data
changes precede this branch. The context slot is internal software data;
the next outer iteration reloads it. This preserves the intended output
algorithm, conditional on the original helper/composition correctness;
a universal whole-program refinement is still unproved.

This actual full listing is42727 bits/3229 instructions, with350
out-of-Q references. It saves5978 bits, but still failsQ. Its original
and merged listings are both preserved. No claim of aQ-fitting minimum,
new smallerU, or universal deadline follows from that saving.

The next concrete implementation opportunity is a generic bounded
serial word-output operation, matching the existing serial inputSPAN.
It could replace the repeatedly emitted one-bit write/software-return
loops. Such an operation must have explicit raw entry/consume/error
equations, output-holder locality, all own-emitter branches and full
code/time accounting. It would be a RULE/ISA CHANGE. It is not
implemented in this checkpoint and is not a whole-rule evaluation
primitive or a claimed sufficient reliability repair.
