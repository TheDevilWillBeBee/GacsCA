# GAW2: three actual gathers, a late-window obstruction, and a changed noiseless completion

This standalone checkpoint keeps **Q=8192, U=128Q=1,048,576, lambda=24, c=104**. It does not change G17 or any accepted earlier source. The constants label the intended original error classification; no stochastic or higher-error theorem is proved here. The new sources are [GAW2D](gray_three_gather_gaw2.py), its [whole emitter](build_gray_three_gather_gaw2.py), the separately named [GAW2R](gray_three_gather_gaw2r.py), and its [whole emitter](build_gray_three_gather_gaw2r.py).

GAW2D uses a112Q late reset and112Q+1 birth, with execution through120Q. Its cached-clock whole evaluator has exact prepared decoded-output deadline failures. GAW2R instead resets at102Q and births at102Q+1. A compositional all-raw bound and physical noiseless period proof close this declared large-ROM word rule. They do **not** close Gray's Q-bit own-programme requirement or his literal stage/rest specification. The full direct emission occupies41,162 bits and1,049 distinct dictionary words; the declared diagnostic code resources occupy270,349 immutable bits. The raw cell has49,037 bits, physically encoded here as496 WORD100 positions rather than Gray's bit positions.

## 1. Exact rule and alphabet

The native fields have widths13,20,1,1,1,1 (Address, Age, Flag1, Flag2, WF1, WF2), totaling37 bits. The98 SF word fields each have five100-bit copies: the45 GAW0D fields, MailL/MailR, and three separate seventeen-word History banks. Thus K=37+98*5*100=49,037. All native GF13 and Age20 patterns are legal since Q=2^13 and U=2^20. Every SF word pattern, including invalid head presence/move/mode/PC/target/args, is quantified. Unused high padding of the six native WORD100 representation rows is zero and is not part of this alphabet. A496-word vector with arbitrary high native padding is not a cell of this declared alphabet.

Relative frame start P=3848 and end4343. The five holders of logical y use offsets S=(0,-2,-1,1,2), so the ith raw holder is y-S[i]. Packet execution, invalid-state handling and finite generic ALUs are inherited unchanged from the frozen GAW0D. No primitive evaluates a whole cell or invokes the host evaluator: CODE looks up a single fixed immutable instruction word; BITCODE a fixed code bit; vector ALUs perform their explicitly finite arithmetic/majority functions. A raw erroneous or invalid virtual code address has the specified zero/error behavior. CODE's8192 word-address space reads11-bit tokens from the declared65,536-bit ROM; missing padding bits are zero; the2048-word dictionary makes every token total. The13-bit early entry metadata is counted separately and fixed by the emission. The own beta contains the literal matching birth address and simulates CODE/BITCODE on arbitrary upper raw PC/register values using the same finite tables.

The native h1 correction, radius8/17 lanes/FULLCOL, WORD100 alphabet, computed-holder service Address, immutable lookup and diagnostic ROM capacity are departures from the literal printed rule. Mailbox erasure is now restored: **computed native Flag1** clears both mail words at every holder. Mailbox and retained History are distinct tracks. Retaining these mechanisms does not make the changed rule Gray-faithful.

## 4. Actual three-gather and flag courier contracts

Take a doubly infinite line. Let logical Info D(y) be arbitrary, with all five physical copies coherent. Lower geometry is canonical Address x modQ, a common lower Age, native flags/WF initially0, and work reset as defined in section6. For each start S_g in{0,32Q,64Q}, a current row with computed Age S_g+1 loads old voted Info into both Mail tracks. During the active interval, L shifts one logical site left per tick (new L(y)=old L(y+1)); R shifts right. Mail clears at stage starts and whenever computed Flag1=1. Historyg is reset only at starts through its own gathering stage, and is retained afterwards. Lane0..16 has delta=lane-8. Its own lane8 captures Info at S_g+1; other lanes capture old R/L at **S_g+2+abs(delta)Q**.

In the first three gathering windows, lower WF sources are identically0 and the initially0 native flags stay0 under canonical common geometry, so Mail is not erased. Induction gives old Mail at capture equal D(y+delta Q): the loaded row is S_g+1 and the old capture row is S_g+1+abs(delta)Q. The furthest third capture is72Q+2. At an actual raw holder of frame word i/copy h, y=gQ+P+i and x=y-S[h], this source is exactly (g+delta)Q+P+i. The checker retains126,480 actual holder/source identities, not head-centre substitutions. No boundary condition or finite-ring wrap is assumed.

At72Q+3, Mem is the bitwise majority of the three retained banks; it is complete at the next early birth72Q+4. Each bank holds the same17 upper raw cells under an encoded start. At upper raw frame words, the early213-update pass computes the actual new upper native fields, including F1/F2. Global Out was reset, and this pass writes only the six native output primaries. It finishes before75Q and therefore before the flag source row75Q. Other Out words stay0 until the late pass.

At75Q, F2 is seeded at P+3 into L and F1 at P+2 into R. The left/right distances to the special primaries3/Q-3 are3848/4339. They arrive well before the old source read row80Q-2. The new rules restrict L to Address[3,P+3] and R to[P+2,Q-3], and hold the endpoint by old OR incoming. Each such route contains one seeded source and is wholly inside its own colony; its endpoint stays equal to its own source through the80Q-1 special Info write. Two earlier component defects are retained rather than silently repaired. ## 5. Why the102Q late start is a changed schedule

The supplied primary source, [Gray pp34–35](../../../../papers_txt/gray_readers_guide.txt), defines stages of lengths32Q,32Q,32Q,16Q,16Q, each with equal active/rest halves. The fourth trickle-down stage is96Q..112Q; its WF sources may be nonzero only in96Q<=Age<98Q. The fifth active window is112Q..120Q. His p35 argument uses the rest separation and a local-error lifetime at mostU/32 to infer that a real1 disturbance can affect at most one gather/active stage. The Workspace resets and retained banks support the temporal majority and ensure damaged work does not persist into later clean periods. His source discussion before80Q is a separate deadline from the fifth-stage output commit.

The chosen native-only early pass implements the p35 requirement to compute the upper flags before80Q; that early computation is allowed by the primary description. Its213-update timing is established for our primitive, not inferred from the asymptotic fifth-stage estimate. For D's noiseless reset encoding, native flags are0 before96Q and all three gathers/early couriers finish before80Q, so their work is held in the original rest intervals. The all-raw equations do not enforce a universal rest lock on damaged controllers: computed Flag1 may still erase Mail. Such behaviour requires the appropriate damaged-history argument, rather than this noiseless theorem. The actual new rest departure is R's execution in104Q..112Q. Gray's real1 active-stage separation and higher-level confinement/temporal-redundancy proof are not borrowed unchanged.

There is a separate noiseless quietness bound sufficient for R. Canonical GF/common Age are preserved for arbitrary lower native flags and arbitrary work: both candidate native Address/Age refinements agree, so either selector yields the same geometry. Therefore the mandatory SF wipe is always false. At current Age98Q the computed WF fields are0 and stay0. With old WF0, the actual Flag1 recurrence becomes (at least3 right-in-colony ones) OR (old self1 and at least2 right-in-colony ones). A terminal zero strip grows left by at least2 cells/tick from the colony's last two cells; arbitrary F1 vanishes withinQ/2 ticks. Once F1 and WF vanish, the corrected Flag2 recurrence becomes (at least4 left-in-colony ones) OR (old self1 and at least2 left-in-colony ones). Its initial zero strip grows right by at least2 cells/tick; arbitrary F2 vanishes within anotherQ/2 ticks. Hence all native flags are0 by99Q. The checker independently verifies24,576 actual scalar cofactors of each recurrence. This uses canonical common-clock lower geometry; it is not a damaged-clock recovery lemma.

R replaces the fourth/fifth boundary by102Q, retains end120Q and final rest120Q..128Q, and has147,455 usable updates after birth. It therefore starts3Q after the proved quiet time and has slack5898 beyond141,557. This changes the fourth stage length to6Q and fifth stage length to26Q; it executes during the printed fourth rest104Q..112Q. Both the original equal-half rest property and the proof's error-window separation require new work in this variant. Keeping lambda24/c104 numerically does not prove those estimates. No E0/higher noisy extension of the quietness, routing or period proof is asserted.

102Q is the latest integer-Q start certified by this specific141,557 upper bound with end120Q: a103Q birth would allow139,263 updates. A pessimistic upper bound exceeding that window is not a lower bound; it does not prove a103Q start fails or that102Q is globally minimal. U is unchanged and no smallerU has been justified.

## 6. Noiseless physical period theorem for the changed R rule

Let F be the fixed total GAW2R rule using its emitted diagnostic ROM beta. For any infinite configuration C in its49,037-bit alphabet, define E(C,A) as follows. Native fields at x are Address x modQ, Age0, Flag1=Flag2=WF1=WF2=0. Every SF word except Info and Programme is0. Each copy of Programme is the fixed beta bit at its logical Address. Logical Info at gQ+P+i is the WORD100 representation row i of C[g], with zero native high padding; all five raw copies at gQ+P+i-S[h] agree. At all other logical positions Info is the arbitrary WORD100 function A, with coherent five copies. Represented and auxiliary positions are disjoint. In particular the special flags3/Q-3 are outside the frame and are not falsely constrained to equal some upper-cell auxiliary fields. E has correctly reset work as an initialization premise, not arbitrary prior lower work.

**Theorem.** For every C and A, with no physical errors on any row, F^U(E(C,A))=E(F(C),0). The natural decoder reads the496 normal logical Info words; its native rows are legal and decode exactly F(C). **C may have all raw native-clock patterns, invalid head metadata, and mutually incoherent SF copies; no upper GF/Age/holder coherence is assumed.** Lower encoding coherence/reset is a separate initialization premise. The141,557 bound is first a prepared-execution theorem; in this zero-error physical period its bank/controller/reset/birth/quiet/no-wipe/travel premises are all derived below. This is one global physical noiseless period, not a finite prepared run.

**Proof.** Canonical Address/common Age are preserved by native candidate equality, and the computed SF wipe is false on all rows, regardless of evolving flags. Before the first WF window all flags0; hence the three actual reset/load/capture inductions in section4 hold simultaneously at every normal primary. All records finish by72Q+2 and persist until U. No unrepresented Info is used in a represented frame gather. At72Q+3 the unanimous temporal vote gives the complete17-cell input bank. Reset clears all early Out/Scratch/heads and the next row births exactly one logical packet at P in each colony, with all five copies. The213-update native-only pass stays inside the proved internal frame; the real five-holder and opcode contracts inductively identify it with the prepared interpreter. Every correct early F1/F2 reaches its own special primary through the proved route-bounded couriers. No later early output is required after those special writes.

The source window96Q..98Q can now drive real lower native flags. The held History banks never reset after64Q and cannot be wiped because Address remains canonical. Mailbox erasure in this window cannot change those already captured records. The native quiet bound in section5 gives all flags0 by99Q. At102Q the late reset clears Out/Scratch/heads/Mem. At102Q+1 the old three History banks reconstruct the exact same complete input bank, simultaneously with a fresh unique pc0 packet. Programme lookup is fixed on every row. The entire lower input bank is readonly throughout execution; output and scratch are distinct tracks. Head and operand travel remain strictly inside the colony frame. The same inductive physical-holder coupling therefore applies to the universal prepared full evaluator for this arbitrary C neighbourhood, including its invalid raw upper packet metadata. All496 output words are F(C[g]) and are complete by birth+141,557<120Q. No data-dependent branch can miss this bound.

After completion, halted heads and outputs are held. No late reset occurs before U. Every logical Out outside the496 normal frame is0, since reset was global and neither early nor late emission writes outside the frame. The special flag Info written at80Q is not an Out write. On the U boundary, new Age0 copies old Out into Info before resetting other work: normal Info becomes F(C), and every unrepresented Info becomes0. Mail, all History, Mem, Out, Scratch, couriers and heads reset to0; Programme remains the correct hardwired bit; native flags remain0. This is exactly E(F(C),0) on the full infinite line. Every site argument involves finitely many local identities, so there is no compactness/boundary assumption. Iterating the same theorem yields noiseless upper transitions at subsequent boundaries. It supplies no iid memory theorem. QED.

The theorem's coherent five-copy/reset start is explicit. A recursively intact self-encoding start is not needed for this theorem, and no adversarial error witness from such a start is claimed here. A pure-E0 or higher-class proof would need correct lower controllers, capture histories, temporary SF redundancy, authentic whole-period rest/refinement, and changed-radius error geometry without assuming this noiseless preparation. All remain open.
