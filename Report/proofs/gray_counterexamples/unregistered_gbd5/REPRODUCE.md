# GBD5 read-only reproduction

From the repository root, using python3:

```sh
python3 Report/proofs/gray_counterexamples/unregistered_gbd5/validate_gbd5.py --output /tmp/GBD5_parent_validation.json
```

The validator checks all frozen new and inherited source/receipt hashes
before and after replay. It recomputes the actual native graphs, local
chronological gather/reset/capture equations, every normal-primary capture
route, complete packing transport, actual birth and two complete selected
native-software trajectories. It compares every emitted artifact byte for
byte and replays the separately accepted raw-Head radius-five cofactor.
Previously accepted GBD4 universal software/arithmetic and GBD3 packing
contracts are reused through their exact manifests and terminal child and
parent replay receipts; unrelated old experiments are not rerun.

The written proof gives the universal clean-prefix composition for every
3387-bit upper raw record and arbitrary unused lower Info. The selected
execution checks supplement that composition and do not replace its
universal software bound. This remains a partial autonomous transducer:
the native prefix is7051 programme bits, but the complete own programme,
authentic early flag delivery, late pass, full period, recursive intact
initializer, noise map and faithful Gray refinement are unproved.
