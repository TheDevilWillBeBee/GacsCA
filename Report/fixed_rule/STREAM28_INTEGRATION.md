# Integrated parallel gather in a fixed self-ROM candidate

2026-09-28. This experiment follows the source-only Git checkpoint
`1ea6239` and the isolated [stream prototype](STREAM_GATHER_PROTOTYPE.md).
It changes only new files in `gacsca/fixed_rule/`, `experiments/fixed_rule/`,
`tests/fixed_rule/`, `Report/fixed_rule/` and receipts under `figs/fixed_rule/`.
The previously validated `packed28_holder_*` rule is untouched.

Gray pp. 28–29 describes simultaneous mailbox streams delivered to fixed
workspace sites. His pp. 31–32 hard-wire the simulator after projecting away
ProgramBit. Gács §§9.2–9.3 permits simulation of an identical or suitably
modified self-correcting rule. The resulting `stream28_holder_*` candidate
retains the old protected raw physical alphabet (154 words, 4090 bits),
projected alphabet (105 words, 2704 bits), radius seven, Q=8192 and U=2^28.
No rule, ROM, register width, or transition kernel depends on encoded depth.

The first three clock stages now use a fixed parallel stream mechanism inside
the **actual complete physical rule**. At each Info MEM site, static `b`
contains a raw field code and 15-bit emission mask. At each History MEM site,
static `d` contains a high-bit-marked `(wire,stage)` acceptance tag. The mark
separates tags from the entry-point word in header MEM site zero. The old
left/right packet registers carry a 64-bit value, wire id and three-bit hop
counter. The physical transition derives one candidate wire for each moving
direction from its own Address and Age, checks the encoded source mask,
launches locally, moves one site per tick, decrements hops at colony
boundaries, and accepts at the tagged History. The first three reset events
no longer boot a serial gather head. No host evaluator inserts evolving
packets. The same rule retains stage-three Flag computation, temporal vote,
stage-five complete encoded raw evaluation, and Info commit.

`stream28_holder_rule.self_description()` describes the stream and all
controller, maintenance, replication and signal behavior. Its compiled
description is stored and evaluated in its **own** fixed packed ROM. The
source metadata are regenerated by its META instructions as part of the
static fields. There is no depth-specific hardware case. Finite depth is
still given through `stream28_holder_initial`'s encoded initial data.

The new full raw self-description has 16,475 word operations; the optimized
and packed computation uses 11,054 word operations, 11,438 virtual ROM
instructions and 4,061 packed instruction rows. It occupies
7,517 physical core sites, including 3,455 memory sites, leaving 670 sites
before the reserved tail. The live result bank requires at least 287 cells;
the current fixed allocation uses 384 as its capacity. The own rule still
requires exactly 689 gathered raw inputs: 97 local and 592 nonlocal. Per
colony, each of three stages delivers 689 words. Their last arrivals are
65,097, 65,095 and 65,094 ticks, all below the fixed 16Q=131,072 window.
Distinct directed wire phases prove absence of healthy same-lane collisions
on canonical geometry. The late serial evaluation takes 179,678,840 ticks.
Extending its active end from 256 million to 264 million within the same
U=268,435,456 period leaves a 2,321,160-tick execution margin. The early
Flag stop and capture margins are 3,348,411 and 5,347,735 ticks. The
compiled rule's dependency DAG has 11,054 nodes, 21,944 operand edges,
critical depth 73, and a maximum layer of 1,020 nodes. This shows spatial
parallel potential, but says nothing yet about a feasible local routing
layout within Gray's 8Q late budget.

## Executed evidence

`python -m experiments.fixed_rule.certify_stream28_holder_rom`: PASS in
8.185 seconds; final receipt
`figs/fixed_rule/stream28_holder_rom_v2.json`. The checker validates the
three route schedules, supplies their expected History values as symbolic
terms, then executes the candidate's own packed ROM instruction by
instruction on 15 colonies. It checks 62,010 history comparisons over
three stages, 180,690 virtual instruction executions, 2,205 metadata
queries, 150 later Flag-signal packets, and all 154 final raw Hold/Info
fields per colony. This is conditional symbolic dataflow; the Histories are
supplied from the independent stream schedule rather than a full physical
evolution. Mutating a packed physical instruction bit causes the final raw
Hold check to fail. The final conservative typed compiler agrees
**structurally on all 154/154 raw outputs** with the original complete
physical description for arbitrary typed neighborhoods, and 96 random
complete input cases agree numerically. The compiler widens a temporary
known-bit bound in the dependency cones of the ten replicated mail hop
counters; this prevents a mask rewrite whose expression exceeded the
independent normalizer's identities. Widening an upper bound is sound.
The first, faster compiler (`stream28_holder_rom_v1.json`) matched only
144/154 outputs structurally, though all 96 numerical cases agreed. A
fallback retaining those original expression trees made the own ROM 8,732
sites and failed Q8192 capacity. Both failed paths are preserved as
diagnostic results.

## Remaining work and decision

This is a source-grounded integrated fixed-rule **candidate**, not a claim of
completed noisy self-simulation. A continuous physical U-tick period with
the new local stream dynamics has not yet been executed. The existing
accelerated CPU backend assumes Data and mail are quiet without a head;
that assumption is false during stream stages. Reusing its skip routine
would silently omit physical launches. A successor executor must schedule
local stream emissions and movement as physical events, verify those event
skips against literal F, and then run at least two successive lower periods
with complete decoded upper controller state. No source repair or noise
robustness follows from this healthy-stream audit.

Q=8192/U=2^28 is retained, but this does **not** reach Gray's U=2^20.
Parallel gather removes the prior 12-million-tick communication bottleneck;
the 180-million-tick serial evaluator now dominates. At Q8192, Gray's
late 8Q budget is 65,536 ticks, requiring roughly 2,742-fold acceleration
of that stage. A local spatial evaluator is the next substantial design
problem. The DAG depth 73 and first-layer width 1,020 justify studying it;
the actual communication layout and space-time bound remain unknown.

`python -m experiments.fixed_rule.measure_stream28_spatial_dag` records the
next evaluator design constraints in
`figs/fixed_rule/stream28_spatial_dag_v1.json`. The 11,054-operation DAG has
21,944 operand edges, depth 73, peak layer width 1,020, and maximum direct
raw-input fanout 38. Its five protected procedure-copy cones each contain
3,036–3,040 operations; 4,916 operations are used by just one such copy,
3,740 by multiple copies, and 2,398 lie outside those procedure cones.
There are 4,732 colony sites outside current MEM and tail banks, counting
existing instruction cells. If a future rule let *all* of them compute in
parallel, the pure work bound would be three ticks; dependency depth is the
real idealized lower bound of 73 ticks. Gray's 65,536-tick late window then
allows an average of at most 897 ticks per critical-path operation for all
routing, replication, computation and synchronization. These figures do
not produce a placed circuit or prove that such a local schedule exists.
