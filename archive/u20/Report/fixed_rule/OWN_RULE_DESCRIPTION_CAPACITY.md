The combined certificate checked **345** scalar local neighborhoods, including 10 neighborhoods with arbitrary typed raw controller replicas, a corrupted holder Address, 125 OUTPUT states, 221 mail states, capture, Info and work-period wrap. The optimized program below was checked on those same states. Receipt: `figs/fixed_rule/stream28_spatial_description_full_v2.json`.

This is a diagnostic evaluator type issue, not a change to the physical AND operation.
