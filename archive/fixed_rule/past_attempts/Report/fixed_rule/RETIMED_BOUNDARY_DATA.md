# Finite-depth termination for the current retimed rule

2026-09-27. The unchanged current rule has an explicit ordinary terminal orbit
including its complete controller state. An exact descriptor check covers all
2^31 normalized Ages and all 154 raw outputs. The same boundary still cannot
repair a single Address-bit defect. This separates an available noiseless
termination construction from the unresolved boundary reliability problem.

## Terminal data and the block relation

Let C(a) have Address Q-1, Age a, Flag1=Flag2=1. All mutable fields are zero
except the +1 backup's head and PC at these clock values:

| Age | s3_head | s3_pc |
|---:|---:|---:|
| 1 | 1 | 0 |
| 150000001 | 1 | 2440 |
| 290000001 | 1 | 4752 |
| 430000001 | 1 | 7065 |
| 1230000001 | 1 | 7064 |
| 1232000001 | 1 | 7065 |

The 49 ROM metadata fields are regenerated by the existing lift iota. On a
homogeneous ring, the full fixed descriptor F satisfies
F(iota C(a), ..., iota C(a)) = iota C((a+1) mod U). Consequently G=pi F iota
has the same orbit, with no distinct terminal transition or new opcode. The
head/PC pulses matter: simply incrementing Age in an otherwise constant cell
does not describe this complete raw orbit.

The physical Age field remains 32 bits, while U=2^31. The orbit proof quantifies
31 independent clock bits, sets the high bit to zero, and truncates the next
Age to 31 bits. It does not confuse the alphabet's clock width with the period.
The initializer rejects out-of-period clocks. These restrictions describe the
orbit, not a change to the physical state alphabet or rule.

Choose any positive number N of these top cells and any finite depth d. Use the
existing finite recursive **initializer** to form E^d(C(a)^N). This is a finite
configuration of N Q^d physical cells; no call to the initializer is part of
evolution. The conditional descriptor-semantic block relation in
[RETIMED_NOISELESS_MACROSTEP.md](RETIMED_NOISELESS_MACROSTEP.md) gives a decoded
top step after U^d physical ticks, and successive top steps remain on the orbit.
No extra hardware register or depth-selected kernel is needed. This consequence
uses the existing block-relation premises; this turn did not rerun a nested
physical execution or establish a new universal backend-equivalence theorem.

The top data is not an organized colony: all its Addresses are Q-1. Periodic
finite-space termination is sufficient for this construction; a physical edge
against a different medium has not been constructed or analyzed here.

## A defect remains permanent

On the infinite line or a periodic ring of at least 11 cells, replace a single
Address by any A in [0,Q), leave all other Addresses Q-1, keep uniform Age and
Flag1=Flag2=1. The complete descriptor's four geometry outputs preserve this
Address map and flags and map Age to (Age+1) mod U. Other raw fields are
unrestricted, including controllers, Signals, Data, metadata and workspace.
Thus the invariant reapplies indefinitely. A single Address bit changing
32767 to 32766 is enough to create a persistent cap defect.

This second check prunes the complete descriptor to geometry, verifies every
remaining input dependency, then quantifies 32 raw clock bits, 15 replacement
Address bits and 22 independent workspace bits. Its 12 cases cover each possible
defect offset -5 through 5 and an unaffected neighborhood. All 2^32 typed input
clocks are included here, with their first-step normalization proved explicitly.
No omitted controller field is silently constrained to zero: verified absence
from the selected outputs' dependency graph makes it unrestricted.

This reproduces the earlier [cap limitation](CAP_DEFECT.md) for the **current**
retimed descriptor. A mutation test shows that a rule can pass the undamaged
complete-orbit check yet fail defect persistence; the statements are separate.
The result supplies no general repair or amplification theorem.

## Source interpretation

Gray pp. 31–32 describes hard-wiring followed by ProgramBit projection to a
specialized self-simulator. Gacs sections 9.2–9.3 provide rule self-description
and block simulation; neither argument requires a general-purpose platform
for this implementation. See the supplied [Gray text](../../../../../papers_txt/gray_readers_guide.txt)
and [Gacs text](../../../../../papers_txt/gacs_2001.txt).

Gacs Definition 2.2 explicitly permits periodic finite space. Section 3
distinguishes eventual forgetting in finite noisy systems from increasing
finite-space reliability times. Accordingly, the remaining cap objective
should be a stated finite-horizon reliability relation and measured failure
rate, rather than an unqualified claim of permanent finite-state immunity.
Those source statements do not prove reliability of our terminal family.
The candidate-B Flag2 and voted-old-Signal/SimBit source qualifications remain.
