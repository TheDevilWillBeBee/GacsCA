# Level-specific finite-tower archive

This is the earlier NumPy/CUDA Gács/Gray implementation with explicit
level-specific towers. Its [original README](README.md) and
[report](Report/REPORT.md) document its evidence and source-fidelity gaps.
It is not the one-fixed-rule construction. The complete original import
layout is available at the pre-cleanup Git checkpoint `bae5fd2`.
The [legacy CUDA source](gacsca/cuda/README.md) is here; its leftover ignored
binary and notebook backups were preserved under the ignored
`figs/legacy_tower/build/gacsca_cuda_residual/` output directory.
Other ignored notebook backups from the former root, `Report/`, and `gacsca/`
directories are preserved under `figs/legacy_tower/backups/`.
