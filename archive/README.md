# Research archive

- [`fixed_rule/past_attempts/`](fixed_rule/past_attempts/) preserves earlier
  fixed-rule candidates, chiefly serial-evaluator constructions, along with
  superseded reports, tests, and experiments.
- [`legacy_tower/`](legacy_tower/) preserves the separate level-specific
  finite-tower implementation and its reports.

The archive is for inspection and reproduction from the source checkpoint
`bae5fd2`. Archived tests and drivers are excluded from current discovery;
their original import paths belong to that checkpoint. No historical data,
figures, logs, or running jobs were moved into this archive.
